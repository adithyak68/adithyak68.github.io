VR Handball Goalkeeper Training System

A Meta Quest 3 training experience for reactive handball penalty saves.

We built a VR-based handball goalkeeper training system that lets players practice reactive penalty saves under different speed and environment conditions. The system provides repeatable game-like shot practice without needing a full team, gym, or live shooter.

Overview

A complete VR training loop for handball goalkeeping.

The system places the user in a goalkeeper role and launches spawned handball shots. The user blocks shots using their VR hands while the system tracks saves, misses, rounds, speed conditions, and environment conditions.

Motivation and Challenge

Handball goalkeepers need fast reactions, spatial judgment, and repeated exposure to penalty shots. Traditional practice depends on court time, a shooter, and consistent setup. Our project uses VR to make focused goalkeeper drills repeatable, while still facing the challenges of believable shot timing, hand collision reliability, depth perception, and distraction-heavy environments.

Experience Modes

Experience Modes

The final build supports controlled drills as well as more game-like pressure by combining environment intensity with shot speed.

Controlled

Calm environment + slow speed

Best for learning the save motion and reading ball direction with lower pressure.

Reactive

Calm environment + game speed

Focuses on faster reactions while keeping visual and audio distraction low.

Distraction

Chaotic stadium + slow speed

Adds crowd atmosphere and stadium visuals while preserving a slower training pace.

Match-like

Chaotic stadium + game speed

The most game-like condition, combining high speed with environmental pressure.

Technical Implementation

Technical Implementation

The project uses Unity and Meta Quest 3 platform capabilities for VR rendering, tracking, and physics. On top of that, we implemented the environment, spawning, interaction, scoring, audio, and demo systems that make the training loop work.

Proposed techniques and approach

The core approach is a geometric and physics-based penalty simulation: spawn the ball from a fixed penalty position, aim it toward a configurable 9-zone target grid, launch it with Rigidbody motion, then evaluate whether the user's tracked VR hand colliders intercept the shot before it reaches the goal/miss area.

Implementation

We relied on the Unity engine, Meta Quest 3 VR runtime, standard Rigidbody physics, and headset/controller or hand-tracking inputs as the platform foundation. The team implemented the handball scenes, ball spawner behavior, shot condition configuration, save/miss detection, HUD, audio feedback, environment switching, and final recorded demo.

Environment system

Calm indoor scene and chaotic stadium scene, with runtime switching between training contexts.

Ball system

Rigidbody ball prefab, static spawner, configurable trajectory, target zones, and speed values.

Audio

Directional audio for crowd and HRTF, ambient stadium music, whistle before the start of a round, and whoosh sound of balls.

Interaction system

Hand colliders and save/miss detection logic for blocking shots with VR hands.

Difficulty system

Slow training speed and game-speed tiers paired with a 9-zone target grid for varied shot locations.

Feedback display

In-VR HUD, score and round counter, round restart button, and game mode selector.

Demo system
